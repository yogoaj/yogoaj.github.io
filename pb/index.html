Mastery 2 · Intelligent & Connected Dashboard — 5 Modul
AI
M2.1 · AI & API Foundation

Konfigurasi provider tanpa memasukkan API key asli ke browser, prompt, atau file HTML. Simpan key melalui Script Properties di server.

API
M2.3 · Public API & Custom API

Custom URL wajib HTTPS, divalidasi di server, dibatasi ke domain yang dipercaya; cegah SSRF. Endpoint publik hanya untuk data sintetis atau agregat yang aman dipublikasikan.

QA
Golden Dataset Contract & Prompt Bertahap

Dataset inti: DATA (Transaction_ID, Date, Region, Product, Category, Quantity, Unit_Price, Discount), REFERENCE, SETTINGS, USERS, AUDIT_LOG. Jangan mengarang Total Profit tanpa Unit_Cost.

Urutan: audit read-only → provider → insight/NLQ → public/custom API → auto report → Stitch UI → regression test. Per file untuk LLM gratis.
