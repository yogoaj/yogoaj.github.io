Bab 1 — Jenis Data Web

Data Apa Saja yang Bisa Diambil dari Web?

Sebelum scraping, pahami dulu jenis datanya. Ini menentukan tools dan metode yang tepat — serta apakah data tersebut legal untuk diambil.

Tiga sumber utama data web

1. HTML Statis — Halaman web biasa

Konten langsung ada di dalam kode HTML saat halaman dibuka. Contoh: tabel BPS, artikel berita, daftar harga di toko online, profil perusahaan. Paling mudah di-scrape dengan BeautifulSoup.

2. HTML Dinamis — Konten yang dimuat JavaScript

Konten baru muncul setelah halaman dimuat, biasanya via JavaScript/AJAX. Contoh: Twitter/X, Instagram, Google Maps, marketplace. Periksa API atau unduhan resmi terlebih dahulu; otomasi browser hanya sesuai izin akses dan ketentuan situs.

3. API (Application Programming Interface)

Website menyediakan "pintu" resmi untuk mengambil data dalam format JSON/XML. Contoh: Twitter API, BPS API, World Bank API. Akses terstruktur yang perlu mengikuti autentikasi, kuota, lisensi, dan ketentuan penggunaan penyedia.

Jenis data penelitian yang bisa dikumpulkan

Data Teks & Sentimen

Ulasan produk, komentar media sosial, berita online — untuk analisis sentimen, topik modeling, NLP.

Data Tabular / Statistik

Tabel angka dari BPS, World Bank, WHO, OECD — langsung bisa masuk ke SPSS atau R.

Data Harga & Ekonomi

Harga saham, komoditas, e-commerce — untuk penelitian ekonomi, manajemen, keuangan.

Data Spasial & Demografi

Data wilayah, populasi, fasilitas publik dari OpenStreetMap, Geoportal BIG.

Data Bibliografi

Metadata jurnal, sitasi, abstrak dari Semantic Scholar API, CrossRef, OpenAlex.

Data Media Sosial

Tweet, posting, hashtag — untuk penelitian komunikasi, pemasaran, perilaku konsumen.

Tips untuk Tesis/Disertasi
Data web dianggap data sekunder. Kamu tetap harus menjelaskan sumber, tanggal akses, metode pengumpulan, dan cara validasi data di Bab 3 Metodologi — persis seperti data survei.

Format data yang dihasilkan

JSON

Output API — paling umum. Mudah dikonversi ke DataFrame pandas.

CSV / Excel

Siap langsung buka di SPSS, Excel, atau R.

XML / HTML

Perlu parsing dulu. Bisa dengan BeautifulSoup atau lxml.

Bab 3 — Tools

Tools Scraping: Dari Tanpa Coding hingga Python

Pilih tools sesuai kemampuan dan kebutuhan. Tidak semua penelitian butuh coding — banyak tools GUI yang powerful untuk kebutuhan akademis dasar.

Tools tanpa coding (No-Code)

Import.io
No-Code

Ekstrak tabel dari website dengan klik. Output langsung ke CSV/Excel. Cocok untuk data tabel sederhana.

ParseHub
No-Code

Antarmuka point-and-click. Bisa menangani halaman dinamis (JS). Periksa paket, batas penggunaan, dan fitur yang berlaku sebelum memilihnya.

Octoparse
No-Code

Alat ekstraksi berbasis antarmuka; periksa fitur/paket dan izin situs sumber. Ketersediaan template tidak berarti situs mengizinkan pengambilan data.

Google Sheets ImportXML
No-Code

Formula bawaan Google Sheets. Cocok untuk mengambil data dari halaman statis langsung ke spreadsheet.

Tools berbasis spreadsheet / low-code

Power Query (Excel)
Low-Code

Bawaan Excel/Power BI. Bisa ambil data dari web, JSON, XML. Sangat powerful untuk akademisi yang familiar Excel.

Postman
Low-Code

GUI untuk mengakses API. Tidak perlu coding — tinggal masukkan URL API dan klik Send. Ekspor ke JSON/CSV.

Ekosistem Python (direkomendasikan untuk tesis)

Requests
Python

Mengambil konten halaman web (HTTP requests). Fondasi dari semua scraping Python.

BeautifulSoup
Python

Parsing HTML. Ekstrak elemen spesifik dari halaman web statis dengan sangat mudah.

Pandas
Python

Manipulasi dan ekspor data. pd.read_html() bisa baca tabel HTML langsung.

Selenium
Python

Otomasi browser untuk alur yang diizinkan; bukan untuk melewati autentikasi, CAPTCHA, atau pembatasan akses.

Scrapy
Python

Framework scraping skala besar. Lebih kompleks tapi sangat powerful untuk dataset besar.

HTTPX / aiohttp
Python

HTTP client asinkron. Jauh lebih cepat untuk memanggil banyak URL sekaligus.

Panduan Memilih Tools
Data tabel statis → Pandas pd.read_html() atau Power Query.

Ratusan halaman sekaligus → Scrapy.
Bab 4 — Contoh Kode Python

Kode Python untuk Latihan

Jalankan persiapan dahulu, lalu pilih contoh. Contoh API memerlukan internet dan mengikuti kebijakan sumber; halaman web dapat berubah. Contoh 3 berjalan tanpa mengakses situs luar.

Persiapan — Dependensi & Permintaan HTTP

Di sel pertama Google Colab: %pip install requests urllib3 beautifulsoup4 pandas lxml. Kemudian jalankan kode berikut. Retry dibatasi untuk error sementara; status lain akan menghentikan proses agar kegagalan tidak dianggap sebagai data kosong.

Pythontimeout · status HTTP · retry terbatas
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

session = requests.Session()
session.headers.update({"User-Agent": "RuangStatistika-Latihan/1.0"})
retry = Retry(total=3, backoff_factor=1,
              status_forcelist=[429, 500, 502, 503, 504],
              allowed_methods=["GET"], respect_retry_after_header=True)
session.mount("https://", HTTPAdapter(max_retries=retry))

def get_ok(url, **kwargs):
    response = session.get(url, timeout=(10, 30), **kwargs)
    response.raise_for_status()
    return response

Contoh 1 — Pilih tabel HTML yang relevan

Contoh tabel GDP Wikipedia. Data yang tersimpan masih mentah; verifikasi sumber, satuan, catatan, dan tahun masing-masing kolom.

Pythonrequests + pandas
from io import StringIO
import pandas as pd

# Jalankan blok persiapan dahulu. Periksa ketentuan sumber.
url = "https://en.wikipedia.org/wiki/List_of_countries_by_GDP_(nominal)"
response = get_ok(url)
# Pilih tabel dari isinya, bukan menganggap tabel indeks 0 selalu benar.
tables = pd.read_html(StringIO(response.text), match="IMF")
candidates = []
for table in tables:
    cols = [" ".join(map(str, c)) if isinstance(c, tuple) else str(c)
            for c in table.columns]
    if any("Country" in c or "Territory" in c for c in cols):
        table.columns = cols
        candidates.append(table)
if len(candidates) != 1:
    raise ValueError("Struktur sumber berubah; periksa kandidat tabel.")
df = candidates[0]
# Tinjau satuan, tahun tiap sumber, dan catatan sebelum analisis.
df.to_csv("gdp_table_raw.csv", index=False)
print(df.head())

Contoh 2 — World Bank: rentang tahun tetap

Parameter date=2000:2023 memilih rentang eksplisit. mrv=24 berarti 24 periode terbaru, bukan rentang tersebut. Nilai nol tetap dipertahankan; nilai hilang dilaporkan.

PythonWorld Bank · pagination
import pandas as pd

url = "https://api.worldbank.org/v2/country/ID/indicator/NY.GDP.PCAP.CD"
rows, page = [], 1
while True:
    payload = get_ok(url, params={"format": "json", "date": "2000:2023",
                                 "per_page": 100, "page": page}).json()
    if not isinstance(payload, list) or len(payload) != 2:
        raise ValueError("Respons World Bank tidak sesuai format data.")
    meta, data = payload
    if not isinstance(meta, dict) or "pages" not in meta:
        raise ValueError("Metadata pagination tidak tersedia.")
    rows.extend(data or [])
    if page >= int(meta["pages"]):
        break
    page += 1

df = pd.DataFrame([{"tahun": int(d["date"]),
                    "gdp_per_kapita_usd": d["value"]}
                   for d in rows if d.get("value") is not None],
                  columns=["tahun", "gdp_per_kapita_usd"])
df = df.sort_values("tahun")
df.to_csv("indonesia_gdp_perkapita_2000_2023.csv", index=False)
print(df)
print("Tahun tanpa nilai:", sorted(set(range(2000, 2024)) - set(df["tahun"])))

Contoh 3 — BeautifulSoup dengan HTML latihan

Latihan parsing judul dan tanggal tanpa URL contoh yang tidak nyata. Untuk situs asli, tentukan selector dan izin berdasarkan struktur sumber.

PythonBeautifulSoup · offline
from bs4 import BeautifulSoup
import pandas as pd

# HTML buatan untuk latihan offline, bukan berita sungguhan.
html_latihan = """
<main>
  <article><h2>Latihan membaca indikator</h2>
    <time datetime="2026-11-01">1 November 2026</time></article>
  <article><h2>Latihan membersihkan tabel</h2></article>
</main>
"""
soup = BeautifulSoup(html_latihan, "html.parser")
hasil = []
for artikel in soup.select("article"):
    judul = artikel.find("h2")
    tanggal = artikel.find("time")
    if judul is not None:
        hasil.append({"judul": judul.get_text(" ", strip=True),
                      "tanggal": tanggal.get("datetime")
                                 if tanggal is not None else None})
df = pd.DataFrame(hasil)
df.to_csv("berita_latihan.csv", index=False)
print(df)

Contoh 4 — OpenAlex: halaman pertama & cursor

Kueri dasar dapat tanpa key. Untuk melanjutkan cursor, buat key gratis melalui akun OpenAlex. Contoh dibatasi tiga halaman jika memakai key; ini belum merupakan pencarian systematic review yang lengkap.

PythonOpenAlex · key opsional / cursor
from getpass import getpass
import pandas as pd

# Kosongkan untuk satu halaman. Key gratis diperlukan untuk cursor lanjutan.
api_key = getpass("OpenAlex API key (opsional untuk halaman pertama): ").strip()
params = {"search": "structural equation modeling Indonesia",
          "per_page": 100, "cursor": "*"}
if api_key:
    params["api_key"] = api_key
max_pages = 3 if api_key else 1   # Batas latihan; bukan seluruh hasil pencarian.
papers = []
for _ in range(max_pages):
    try:
        payload = get_ok("https://api.openalex.org/works", params=params).json()
    except requests.RequestException:
        # Jangan cetak URL exception: URL dapat memuat API key.
        raise RuntimeError("Akses OpenAlex gagal; periksa key/kuota dan coba lagi.") from None
    if not isinstance(payload, dict) or "results" not in payload:
        raise ValueError("Format respons OpenAlex tidak sesuai.")
    results = payload["results"]
    papers.extend({"id": r["id"], "judul": r.get("title"),
                   "tahun": r.get("publication_year"),
                   "sitasi": r.get("cited_by_count"), "doi": r.get("doi")}
                  for r in results)
    next_cursor = payload.get("meta", {}).get("next_cursor")
    if not results or not next_cursor or next_cursor == params["cursor"]:
        break
    params["cursor"] = next_cursor
df = pd.DataFrame(papers, columns=["id", "judul", "tahun", "sitasi", "doi"])
df = df.drop_duplicates("id")
df.to_csv("paper_sem_indonesia.csv", index=False)
print(f"Tersimpan {len(df)} karya; periksa cakupan dan relevansi secara manual.")
Periksa hasil sebelum analisis
Simpan tanggal akses, parameter, metadata, jumlah halaman, dan alasan baris dikeluarkan. Jangan membagikan key di notebook, log, atau repository. Jika akses gagal, periksa dokumentasi; jangan melewati pembatasan situs.
Bab 5 — Etika & Legal

Etika & Aspek Legal Web Scraping

Ini bagian yang paling sering diabaikan mahasiswa. Pembimbing dan reviewer jurnal semakin kritis terhadap sumber data web — pastikan kamu aman secara etis dan legal.

Apa yang boleh dan tidak boleh di-scrape?

✅
Prioritaskan: Data dengan lisensi dan ketentuan yang mengizinkan tujuan penggunaan Anda, terutama unduhan/API resmi. Dapat dilihat publik bukan otomatis izin mengambil atau memublikasikan ulang.
⚠️
Perlu perhatian: Konten berita dan blog (cek robots.txt dan ToS), data e-commerce, media sosial (ada API resmi — gunakan itu), data yang bisa diidentifikasi individu (GDPR/UU PDP).
❌
Hindari: Melewati kontrol akses, menggunakan kredensial tanpa izin, mengabaikan ketentuan sumber, atau menyebarkan konten/data pribadi tanpa dasar penggunaan yang sesuai. Nilai kewajiban privasi, hak cipta, dan persetujuan etik sesuai konteks penelitian.

Cek robots.txt sebelum scraping

File robots.txt mengatur perilaku crawler. Instruksinya bukan izin akses, lisensi penggunaan data, atau pengganti Terms of Service. Tidak adanya larangan robots juga tidak berarti penggunaan bebas.

URLCek manual di browser
https://www.namadomain.com/robots.txt

# Contoh isi robots.txt:
User-agent: *
Disallow: /private/
Disallow: /user-data/
Allow: /public/

Checklist etika sebelum scraping

  • 1
    Baca Terms of Service (ToS) website yang akan di-scrape. Periksa izin pengambilan otomatis, tujuan penggunaan, penyimpanan, dan redistribusi pada versi ketentuan yang berlaku.
  • 2
    Cek robots.txt dan hormati instruksi Disallow.
  • 3
    Ikuti rate limit penyedia, gunakan caching, dan hormati Retry-After pada HTTP 429. Delay 1–2 detik bukan jaminan izin atau bebas pemblokiran.
  • 4
    Minimalkan data pribadi, lindungi penyimpanan, dan dokumentasikan dasar penggunaan serta persetujuan etik yang diperlukan. Data publik tetap dapat mengandung informasi pribadi.
  • 5
    Cantumkan sumber dengan jelas di metodologi penelitian — tanggal akses, URL, dan metode pengumpulan.
  • 6
    Gunakan API resmi jika tersedia — lebih aman, stabil, dan sesuai ToS. API biasanya lebih cepat dari scraping.
Catatan untuk Jurnal Internasional
Reviewer jurnal Q1/Q2 sering menanyakan persetujuan etis (ethical clearance) untuk penelitian yang melibatkan data pengguna dari media sosial, bahkan jika datanya "publik". Siapkan argumen etis yang jelas di bagian metodologi.
Bab 6 — Sitasi & Pelaporan

Cara Melaporkan & Mensitasi Data Web (APA 7th)

Data dari web harus disitasi dan dilaporkan dengan benar di Bab 3 Metodologi dan Daftar Pustaka. Berikut format yang benar sesuai APA 7th edition.

Format sitasi untuk berbagai sumber web

Data dari API Lembaga Resmi (World Bank, BPS)
Format APA 7th
World Bank. (n.d.). GDP per capita (current US$) — Indonesia [Data set]. Retrieved [tanggal akses sebenarnya], from https://data.worldbank.org/indicator/NY.GDP.PCAP.CD?locations=ID . Gunakan tahun/versi rilis jika dataset menyediakannya; jangan mengganti tahun rilis dengan tahun akses.
Data dari BPS
Format APA 7th
Badan Pusat Statistik. ([tahun rilis]). [Judul tabel/dataset persis dari sumber] [Data set]. [URL tabel atau halaman dataset]. Cantumkan versi/periode, tanggal akses bila data berubah, dan parameter API dalam metodologi; jangan hanya menautkan beranda API.
Artikel berita yang di-scrape
Format APA 7th
[Nama penulis]. ([Tahun, tanggal dan bulan]). [Judul artikel sesuai sumber]. [Nama media]. [URL artikel]. Isi hanya dari artikel yang benar-benar digunakan; contoh ini adalah template, bukan berita nyata.
Data dari media sosial (Twitter/X)
Format APA 7th
[Nama akun] [@username]. ([Tahun, tanggal dan bulan]). [Maksimal 20 kata awal isi postingan] [Post]. [Platform]. [URL postingan]. Pertimbangkan apakah tautan atau kutipan dapat mengidentifikasi peserta; ikuti protokol etik penelitian.
Dataset hasil scraping yang kamu buat sendiri
Format APA 7th
[Nama pembuat]. ([Tahun]). [Judul dataset] ([Versi]) [Data set]. [Repositori]. [DOI atau URL]. Publikasikan hanya data yang boleh dibagikan. Untuk dataset tidak dipublikasikan, jelaskan akses dan statusnya sesuai pedoman penulisan.

Cara melaporkan metode scraping di Bab 3

Template paragraf metodologi pengumpulan data web

Data penelitian ini dikumpulkan melalui teknik [web scraping / akses API] terhadap [nama sumber] pada periode [rentang tanggal]. Pengambilan data menggunakan bahasa pemrograman Python dengan library [nama library]. Data yang dikumpulkan meliputi [sebutkan variabel] dengan total [N] observasi. Dasar akses dan penggunaan data adalah [lisensi/izin/ketentuan yang benar-benar diverifikasi], dengan pembatasan [rincian]. Pertimbangan privasi dan etik: [langkah yang dilakukan]; robots.txt diperiksa sebagai panduan crawler, bukan izin penggunaan. Data disimpan dalam format [CSV/JSON] dan diproses menggunakan [nama software].

Hal wajib disebutkan di metodologi

  • Nama sumber data (URL lengkap)
  • Tanggal atau rentang waktu pengambilan data
  • Tools/bahasa pemrograman yang digunakan
  • Jumlah observasi yang berhasil dikumpulkan
  • Cara validasi/pembersihan data (cleaning)
  • Pertimbangan etis dan kepatuhan ToS
Tips Reproducibility
Simpan kode scraping kamu di GitHub dan cantumkan linknya di lampiran tesis. Ini standar transparansi penelitian modern dan sering diapresiasi reviewer jurnal. Kamu juga bisa simpan dataset di Zenodo.org untuk mendapatkan DOI permanen.
